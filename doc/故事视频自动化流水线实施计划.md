# 故事视频自动化流水线 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现第一版无 UI 故事视频自动化后端闭环：项目、分镜、参考资产、分镜图、逐分镜视频任务、参考图 prompt manifest、即梦视频模式路由和恢复继续。

**Architecture:** 在现有 FastAPI + SQLAlchemy + Worker + Dreamina provider 上扩展项目级故事视频模型和服务。故事流水线不替换现有 `Job/Asset` 与 `VideoJob/VideoAsset`，而是新增 `StoryProject` 等模型作为项目层编排，并通过已有图片/视频资产表关联实际产物。

**Tech Stack:** Python、FastAPI、SQLAlchemy、Pydantic、pytest、Dreamina CLI、SQLite/Alembic。

---
